# Decisions

- **Static export:** Next.js App Router with `output: "export"` and trailing slashes, matching the Vercel static-only requirement.
- **Versions:** Next.js 16.1.7 (latest stable shown on npm at scaffold time; 16.2 was still canary), Tailwind CSS 4.3.3, Motion 13.4.6, GSAP 3.15.0, Lenis 1.3.26, Lucide React 1.51.0 and Sharp 0.35.4. Motion, GSAP and Lenis will be loaded only for the interactions that need them.
- **Tailwind v4 integration:** use the official `@tailwindcss/postcss` plugin and keep brand values in `styles/tokens.css`.
- **Asset pipeline:** source assets remain in `assets-src`; scripts generate optimized local files under `public`. Never hotlink source sites.
- **Flyer archive:** descriptive slugs preserve recognizable dates; `public/flyers.manifest.json` maps original filenames to processed paths and includes status and alt text.
- **Typography:** Bricolage Grotesque for display and body, Instrument Serif for editorial emphasis, and DM Mono for labels. `next/font/google` self-hosts the font files during the build.
- **Design system:** the Phase 2 header, footer, buttons, badges, placeholders, logo and responsive `<picture>` wrapper are shared components. The opening page is a visual preview surface; the full homepage sequence begins in Phase 3.
- **Link safety:** internal page paths, social URLs, contact details and source-image paths are centralised in `content/site.ts`. External links open in a new tab with `noopener noreferrer`.
- **Mobile navigation:** at compact widths the header uses a keyboard-operable menu with focus containment, Escape close and focus return. Desktop navigation exposes `aria-current` for the active page.
- **Contrast:** bone `#F4EEE6` and muted `#A9AEC9` are the small-text foregrounds on navy. Flame red is reserved for large type, icons and borders; orange is used for text only at large/bold sizes. A light theme is deferred to protect the schedule.
- **Measured contrast on page navy `#00061F`:** bone is 17.42:1, muted is 9.16:1, red is 3.84:1, orange is 5.83:1 and amber is 11.10:1. Body copy and labels use bone or muted; red remains decorative/large, with orange and amber for calls to action and emphasis.
- **Time handling:** recurring schedule is represented with WAT times and timezone-free recurrence rules; Africa/Lagos is UTC+1 year-round, so no DST conversion is needed.
- **Placeholders:** null map, giving, Waystream and Mixlr values remain explicit in `content/site.ts`; UI components can render designed fallbacks without inventing links.
- **Phase 3 featured gathering:** An active weekly session within its published start/end window takes priority. Otherwise, recurring weekly programs populate the This Week strip and do not displace a concluded flagship recap. This preserves the explicit October 2026 acceptance state: EPAC’26 remains featured while weekly prayer, Sunday service and Monthly Encounters appear as the next three program series. A future published one-off event takes the featured slot.
- **Phase 3 occurrence cards:** The homepage shows the next upcoming occurrence for each published recurring program, one per program. It skips a same-day service in the homepage strip to keep the next gathering list forward-looking. Times are constructed as Africa/Lagos local times (UTC+1) and never depend on the visitor’s timezone.
- **Phase 3 motion fallback:** Ken Burns, ember canvas, marquees, Lenis and the desktop Five Answers pin run only when reduced motion is off and device/data conditions allow it. The static layout remains visible before JavaScript and on constrained devices. Poster thumbnails are generated as local WebP files with a 40KB maximum.
- **Phase 5 metadata:** One metadata helper builds per-route canonical, Open Graph and Twitter metadata from `site.siteUrl`; the Vercel placeholder URL remains the fallback until the church domain is confirmed. The share card is generated locally from the approved logo and EPAC flyer artwork, never the illustrative hero photo.
- **Phase 5 structured data:** Organization/Church schema uses only verified identity, parent network, address and supplied public links. Event schema is emitted only for published, dated future flyers; recurring gatherings stay in the calendar export rather than being presented as individual dated events.
- **Phase 5 security headers:** Vercel applies same-origin defaults, blocks objects and external forms, restricts frames to YouTube and sets modern referrer, MIME and permissions policies. CSP allows inline script/style needed by the static Next.js export and existing motion styles; it does not allow `eval` or third-party scripts.
- **Phase 5 transfer size:** The shared header keeps the approved transparent wordmark but serves a 440px WebP derivative for its 110px display, preserving retina sharpness without transferring the original 1685px asset. Hero AVIF/WebP candidates remain local and responsive.
- **Additional packages:** Sharp is needed to meet the requested local AVIF/WebP pipeline. No other dependencies were added beyond the fixed stack.
